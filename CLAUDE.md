# ميزان العفش (fair-furniture-egypt)

The site is a single file, `index.html`, served by GitHub Pages from `main`, root.
Live: https://iwakiel.github.io/fair-furniture-egypt/

## To update

1. Replace `index.html` with the new file I give you, exactly as it is.
2. Check its `<title>` is "ميزان العفش".
3. Commit with a clear message and push to `main`.
4. Wait for the Pages deploy to finish.
5. Confirm the live page shows the change.

## Rules

- Never commit tokens or credentials.
- Never edit `index.html` by hand unless I ask; new versions come from my Claude project.
